# Фитнес-клуб — WPF-приложение

[![Открыть проект на GitHub](docs/github-qr.png)](https://github.com/drpcll/kurs)

Репозиторий проекта: https://github.com/drpcll/kurs

Информационная система «Фитнес-клуб» для работы клиентов и администраторов
(курсовой проект по МДК 05.02).

## Требования

- Windows 10/11;
- Visual Studio 2019 или 2022 с рабочей нагрузкой **«Разработка классических
  приложений .NET»**;
- .NET Framework 4.8 (входит в состав Windows 10/11);
- шрифт **Century Gothic** (установлен в Windows по умолчанию).

## Запуск

1. Открыть `FitnessClub.sln` в Visual Studio.
2. Нажать **F5** (или «Сборка → Собрать решение»).
3. Ввести учётные данные пользователя.

| Роль | Логин | Пароль |
|------|-------|--------|
| Администратор | `admin` | `admin` |
| Клиент | `client` | `client` |

## Состав окон

| Файл | Назначение |
|------|------------|
| `LoginWindow.xaml` | авторизация, проверка полей, переход в кабинет по роли |
| `ClientMainWindow.xaml` | кабинет клиента: абонемент, разделы, ближайшие занятия |
| `AdminMainWindow.xaml` | панель администратора: показатели, разделы, таблица клиентов |

Общие ресурсы оформления находятся в `Styles/Theme.xaml`: палитра, шрифты,
стили кнопок, полей ввода и таблицы.

## Оформление

| Цвет | Назначение |
|------|------------|
| `#141418` | основной фон |
| `#1F1F26` | панели и карточки |
| `#2E2E38` | границы, поля ввода |
| `#7A1F3D` | основной вишнёвый акцент |
| `#A62B52` | наведение и активные элементы |
| `#E8C7D2` | вторичный акцент и подписи |
| `#F5F2F3` | основной текст |

Шрифт интерфейса — **Century Gothic**.

## Данные

Начальные данные (клиенты, абонементы, расписание) заданы в `Models.cs`
и совпадают с тестовым набором базы данных `user95_db`
(сервер `stud-mssql.sttec.yar.ru`, порт `38325`, таблицы `KURS_*`).

## Структура проекта

```
FitnessClub/
├── App.xaml, App.xaml.cs          — точка входа, подключение темы
├── Styles/Theme.xaml              — палитра и стили элементов
├── LoginWindow.xaml(.cs)          — окно авторизации
├── ClientMainWindow.xaml(.cs)     — главное окно клиента
├── AdminMainWindow.xaml(.cs)      — главное окно администратора
├── Models.cs                      — модели строк и начальные данные
├── Properties/AssemblyInfo.cs
├── FitnessClub.csproj
└── FitnessClub.sln
```
